A simple and responsive Pomodoro productivity timer built using HTML, CSS and JavaScript.

## 🌐 Live Demo

Coming soon

## ✨ Features

- 25-minute focus timer
- 5-minute break timer
- Start, pause and reset
- Skip session
- Focus and break modes
- Completed session counter
- Dark mode
- Local Storage
- Responsive design
- Mobile friendly

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Browser Timer API
